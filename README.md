# mobile-ds-guides

Behavioural rules for the mobile design system, published as a static GitHub
Pages site. Each guide pairs prose with an interactive stand you can scroll and
tune, so a rule can be checked rather than argued about.

**Site:** https://tomsvorobovich-qic.github.io/mobile-ds-guides/

- `guides/*.md` — the rules
- `stands/*.html` — interactive demos, no dependencies
- `assets/` — shared stylesheet and stand behaviour

The surface palette in `assets/stand.css` is a placeholder. Swap `--surface-*`
for the real design tokens.
